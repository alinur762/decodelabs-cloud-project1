03hop

AWS Cloud Infrastructure for University Student Portal

A team-based, production-style cloud infrastructure designed and deployed on AWS for a university student portal. Built with a custom VPC and public/private subnet separation, IAM role-based groups with MFA, EC2 web servers behind Security Groups, S3 with tiered access levels, and RDS MySQL isolated in a private subnet — monitored through CloudWatch with real-time alarms.
